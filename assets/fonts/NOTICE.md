# Noto Sans SC

- Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Source file: `NotoSansSC[wght].ttf`, stored here as `NotoSansSC-Variable.ttf` without modifying its contents.
- Upstream Git blob SHA-1: `fb0637bafbcd804fe32152370a1225990745b4bc`
- License: SIL Open Font License 1.1; see `NotoSansSC-OFL.txt`.
- Weight axis: 100–900. Flutter 3.41 or newer applies `FontWeight` to the font's `wght` axis, including genuine 500 and 600 weights.

The full font is bundled for offline use and Chinese text beyond the built-in UI labels. Avoid replacing it with an incomplete UI-only subset or changing Chinese text to a system font that lacks the required weights. Code editors continue to use JetBrains Mono, with this font available as the Chinese fallback.
